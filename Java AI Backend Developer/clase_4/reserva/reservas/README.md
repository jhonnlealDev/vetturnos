# Gestor de Reservas - Marta Peluquería

Aplicación de consola (CLI) desarrollada en Java para gestionar las citas, evitar cruces de horarios y calcular la facturación diaria de la peluquería.

## Características
- **Agendar**: Registro de clientes con validación de horarios y servicios.
- **Listar**: Visualización ordenada de las citas agendadas.
- **Cancelar**: Eliminación de reservas con ajuste automático de cupos.
- **Editar**: Modificación de reservas existentes.
- **Reporte**: Cálculo automático de ingresos según el servicio.

## Requisitos
- Tener instalado [Java JDK](versión 8 o superior).

2. Abre tu terminal en la carpeta donde guardaste los archivos `.java`.
3. Compila el proyecto con el siguiente comando:
