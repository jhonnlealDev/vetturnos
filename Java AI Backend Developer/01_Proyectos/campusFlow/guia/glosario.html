📚 Glosario de Desarrollo Java & Spring Boot

Diccionario interactivo de conceptos, anotaciones y términos clave del proyecto CampusFlow

@Entity
JPA / Hibernate
Anotación que marca una clase Java como una Entidad de Persistencia. Indica a Hibernate que esta clase corresponde a una tabla en la base de datos MySQL.
@Entity
@Table(name = "usuarios")
JpaRepository
JPA / Hibernate
Interfaz de Spring Data JPA que proporciona métodos predefinidos para realizar operaciones CRUD (Create, Read, Update, Delete) sin escribir SQL manual.
public interface UsuarioRepository extends JpaRepository<Usuario, Long>
@Service
Spring Boot
Anotación que indica que una clase pertenece a la Capa de Negocio (Service Layer). Allí se procesa la lógica principal antes de interactuar con la base de datos o el controlador.
@Service
public class UsuarioService { ... }
@RestController
HTTP & REST
Anotación que combina `@Controller` y `@ResponseBody`. Le indica a Spring que los métodos de esta clase responderán directamente peticiones HTTP en formato JSON.
@RestController
@RequestMapping("/api/usuarios")
Constructor Injection
Arquitectura
Patrón de diseño donde las dependencias se pasan a través del constructor utilizando campos `private final`. Es la mejor práctica recomendada por Spring en lugar de `@Autowired`.
public UsuarioService(UsuarioRepository repo) { this.repo = repo; }
@Transactional
Spring Boot
Asegura que un método se ejecute dentro de una transacción de base de datos. Si ocurre un error, hace rollback automático. Con `readOnly = true` optimiza las consultas de lectura.
@Transactional(readOnly = true)
@RestControllerAdvice
HTTP & REST
Permite capturar excepciones lanzadas en cualquier controlador de la aplicación para responder con respuestas JSON limpias y estandarizadas (ej: 404 Not Found, 500 Error).
@ExceptionHandler(ResourceNotFoundException.class)
Maven (pom.xml)
Java Core
Herramienta de gestión y construcción de proyectos Java. El archivo `pom.xml` declara todas las dependencias (librerías) y plugins necesarios.
<dependency>...</dependency>
Environment Fallback
Spring Boot
Sintaxis `${VARIABLE:default}` en `application.properties` que intenta leer la variable del sistema y, si no existe, usa el valor por defecto configurado.
${DB_USERNAME:root}
Domain Architecture
Arquitectura
Organización del código por módulos del negocio (`usuarios`, `cursos`) que contiene sus propias subcarpetas `model`, `repository`, `service` y `controller`.
com.devsenior.campusFlow.usuarios.service
Clean Code
Arquitectura
Conjunto de principios de programación orientados a escribir código legible, mantenible y simple. Incluye nombres descriptivos, funciones pequeñas con una sola responsabilidad (SRP) y evitar duplicación (DRY).
SRP, DRY, Nombres Explicativos
@Embeddable
JPA / Hibernate
Anotación que marca una clase cuyos atributos se incrustarán directamente en la tabla de la entidad que la utilice (`@Embedded`), facilitando la reutilización y el diseño limpio sin crear tablas adicionales.
@Embeddable
public class PreferenciasUsuario
@Enumerated
JPA / Hibernate
Anotación que define cómo se debe persistir un tipo Enumerado en la base de datos. Con `EnumType.STRING`, se almacena el nombre del valor constante (ej: "CLARO", "OSCURO") en lugar de su índice cardinal.
@Enumerated(EnumType.STRING)
private TemaVisual tema;
@OneToMany
JPA / Hibernate
Define una relación de uno a muchos entre entidades (ej: un Instructor dicta muchos Cursos). El atributo `mappedBy` indica el nombre de la propiedad en la entidad contenedora.
@OneToMany(mappedBy = "instructor")
private List<Curso> cursosDictados;
@ManyToMany
JPA / Hibernate
Define una relación de muchos a muchos entre entidades (ej: un Estudiante se inscribe en muchos Cursos y un Curso tiene muchos Estudiantes).
@ManyToMany(mappedBy = "estudiantes")
private List<Curso> cursosInscritos;
@ManyToOne
JPA / Hibernate
Define la relación donde muchas instancias de una entidad (ej: Curso) se asocian con una sola instancia de otra (ej: Usuario/Instructor). Se combina con `@JoinColumn` para especificar la clave foránea.
@ManyToOne
@JoinColumn(name = "instructor_id")
@JoinTable
JPA / Hibernate
Configura el nombre y las columnas clave foráneas de la tabla intermedia generada en una relación `@ManyToMany` entre dos entidades.
@JoinTable(name = "curso_estudiante", ... )
DTO (Data Transfer Object)
Arquitectura
Objeto diseñado exclusivamente para transportar datos entre capas de la aplicación sin exponer directamente las entidades de la base de datos JPA.
CrearUsuarioRequest, ActualizarUsuarioRequest, UsuarioResponse
Bean Validation
Spring Boot
Anotaciones estándar de Java/Jakarta (`@NotBlank`, `@Email`, `@NotNull`, `@Size`) para validar automáticamente el cuerpo de las peticiones HTTP antes de ser procesadas por el backend.
@NotBlank(message = "El nombre es obligatorio")
Mapper (Mapeador)
Arquitectura
Clase o componente encargado de transformar objetos DTO a Entidades JPA y viceversa, aislando la lógica de conversión en una única responsabilidad.
com.devsenior.campusFlow.usuarios.mapper
